# Security

Если вы считаете, что в этом проекте есть уязвимость или вредоносное поведение, пожалуйста, создайте Issue в этом репозитории или напишите владельцу через профиль GitHub. Я отвечу и разберу обращение.

If you believe this project contains a vulnerability or malicious behavior, please open an issue in this repository or contact the owner via the GitHub profile.

Проект распространяется только в виде открытого скрипта, без исполняемых файлов. Скрипт использует задания Планировщика, автозапуск и встроенный код C# только по действиям пользователя (см. README). Если антивирус на что-то ругается, сообщите об этом в Issue и приложите название детекта.
